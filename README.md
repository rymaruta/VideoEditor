# VideoEditor

YouTubeショート動画向けの動画編集デスクトップアプリ(Electron + React + TypeScript)。

## 主な機能

- 動画・音声インポート、メタデータ取得、サムネイル生成
- タイムライン編集(クリップ端をドラッグしてリアルタイムにトリム・カット・並び替え・削除・再生速度変更)
- 動画トラック+複数の音声トラック(BGM/ナレーション用、追加・削除・ミュート・音量調整)
- 音声分離: 音声付きの動画クリップを選択して「音声を分離」を押すと、そのクリップの音声だけを独立した音声トラックに切り出せる。動画側は無音になり、切り出した音声はBGM/ナレーションと同じように単独で音量調整・ミュート・移動ができる(再生速度が1x以外のクリップは分離不可)
- 複数動画トラック(PiP/顔出し合成): メインの動画トラックに加えて、「動画トラック(PiP)」を追加するとワイプ(ピクチャーインピクチャー)として画面に重ねて合成できる。トラックごとに表示位置(4隅から選択)・サイズ・表示/非表示を設定可能。プレビューでリアルタイムに合成表示され、書き出し時もffmpegのoverlayフィルタで同じ位置・タイミングに正しく合成される(重ねる動画自身の音声もミックスされる)。動画トラックを追加しない場合は今まで通り単一トラックとして扱われる
- クリップ間トランジション(クロスフェード/フェード/ワイプ)
- 無音区間の自動検出→確認→カット
- 自動テロップ生成(オフライン音声認識、日本語・英語・中国語・韓国語・スペイン語・フランス語・ドイツ語から音声の言語を選択可能。要インターネット接続は初回のモデルダウンロード時のみ)
- リッチなテロップ装飾(フォント・サイズ・縁取り・影・背景ボックス・文字間隔・複数行入力・回転・アニメーション)
- テロップのアニメーションはフェードイン・ポップイン・スライドイン(上/下)・バウンス・タイプライターの6種類から選択可能(書き出し時のASS字幕にも反映)
- テロップはプレビュー画面で直接ドラッグ、またはX/Y座標の数値入力で自由な位置に配置可能(書き出し時にも同じ位置・回転角度を反映)
- テロップのスタイルをワンクリックで複製可能
- 単語ごとのハイライト字幕(カラオケ字幕): 自動テロップ生成時に「単語ごとにハイライト」を有効にすると、発話に合わせて単語単位で色が切り替わる字幕を生成(ハイライト色は変更可能。書き出し時のASS字幕もカラオケタグ(\k)で同期再現)
- YouTube Shorts の実際の画面UI(いいね・コメント・共有・チャンネル情報)を重ねたプレビュー表示で、テロップが隠れないか確認可能
- プレビュー再生(9:16 / 16:9 アスペクト比切替対応)。実サイズ表示ボタンでプレビューを画面いっぱいに拡大表示(Escで解除)、音量調整・ミュート、再生バーをクリックしての任意位置シークにも対応
- ショート動画のトレンド構成テンプレート(フック→本編→CTA、ジャンプカット等の定番パターンを自動適用)
- YouTube Data API(公式)によるトレンド・キーワード調査(メタデータ表示のみ、動画のダウンロードは行いません)
- 書き出し画質(解像度480〜1440・圧縮率プリセット)を選択可能
- 長尺(2時間級)ソース動画にも対応した書き出し(ffmpegによるカット済みクリップのみを処理)
- VOICEVOX連携によるナレーション音声合成(ずんだもん等、公式キャラクターボイスのみ対応)
- 編集の効率化機能: Undo/Redo、キーボードショートカット、クリップのコピー&貼り付け、タイムラインのズーム、波形表示
- レイアウトのリサイズ(左右パネルの幅・プレビューとタイムラインの高さ境界をドラッグで調整可能。サイズは次回起動時も保持)。左右パネルの境界にある丸ボタンでメディアパネル・右パネルをそれぞれ個別に折りたたみ可能で、タイムラインの表示領域を最大化できる(折りたたみ状態も次回起動時に保持)
- タイムラインの再生位置(プレイヘッド)をドラッグでスクラブ操作可能(クリックでのジャンプに加えて、つまみをつかんで連続的に移動できる)
- 右パネルのタブをグループ分け(編集系/公開系)し、各タブにツールチップを追加
- プロジェクトの保存/読み込み(`.veproj`ファイル)、未保存変更のインジケーター
- 素材のアスペクト比がプロジェクトと異なる場合の警告表示(黒帯が入ることを事前に確認可能)
- スマートリフレーム(自動クロップ配置): アスペクト比が異なる素材について、黒帯(レターボックス)の代わりに映像の視覚的な情報量が多い領域を自動検出してクロップし、画面いっぱいに表示(トリム画面から実行、検出結果は手動で中央に戻すことも可能)
- 書き出し完了後にファイルを再生/フォルダを表示するボタン
- タイムラインのクリップをドラッグ&ドロップで並び替え
- AIハイライト自動検出(シーンチェンジ+音量変化を解析し、盛り上がり区間の候補を提示)
- サムネイル自動生成(タイムラインから候補フレームを抽出し、テキストを合成してダウンロード)
- テンプレートからの自動カット(素材のハイライト検出結果を使い、テンプレート構成に沿ってタイムラインとテロップを自動生成)
- BGM・効果音ライブラリ(Jamendo / Freesound の公式APIで著作権フリー音源を検索・プレビューし、音声トラックに直接追加)
- ゲームトレンド分析(YouTube公式APIで日本のゲームカテゴリ急上昇動画を取得し、そのタイトル・サムネイル画像だけを根拠にGeminiが今バズっていそうなゲーム名・シーンの特徴を要約。実行するたびに最新データを取得)
  - トレンド時系列比較: 前回の分析結果をローカルに保存し、「新規」「継続」のゲームを比較表示
  - サムネイル視覚傾向分析: 上位動画のサムネイル画像をGemini(マルチモーダル)に渡し、配色・構図・文字入れの傾向を分析
  - バズる要素の構造化抽出: タイトルのフック手法(数字訴求・疑問形・煽り文句など)を分類して提示
  - 次にやるべきゲームの推薦: 抽出したゲームの中から今動画を作るのに最も良さそうな1本を、根拠(急上昇動画の件数・新しさ・競合の少なさ等)付きで明示
- ラウドネス正規化(書き出し時に元動画・BGM・ナレーションの音量差をYouTube推奨値(-14 LUFS)へ自動で揃える、ON/OFF切替可能)
- バッチ書き出し(アスペクト比・解像度・画質の組み合わせを複数登録し、フォルダを選ぶだけで一括生成)
- BGMオートダッキング(音声トラックごとにON/OFF切替可能。本編の音声がある区間だけそのトラックの音量を自動で下げ、ナレーション/セリフを聞き取りやすくする)
- タイムラインのスナップ機能(クリップのトリムや音声クリップのドラッグ移動時に、再生位置・動画クリップの境界・他のクリップの端・テロップの開始/終了に自動で吸着)
- フィラーワード自動検出・カット(オフライン音声認識で「えーと」「あの」等の言い淀みを検出し、無音カットと同じUIで確認してから削除)
- テキストベース編集(クリップの発話内容を単語単位で文字起こし表示し、不要な単語・フレーズをクリック(Shift+クリックで範囲選択)して選ぶだけで、対応する動画区間を自動でタイムラインからカット。タイムラインで秒数を探す手間なく、テキストを読みながら編集できる)
- 投稿メタデータ自動生成(「投稿準備」タブ。タイムラインのテロップ内容とサムネイル候補フレームを根拠に、GeminiがYouTube投稿用のタイトル案(複数のフック手法別)・概要欄・ハッシュタグ・固定コメント案を作成。各項目をワンクリックでコピーしてそのままYouTube Studioに貼り付け可能。タイトル案・固定コメント案は個別に再生成も可能)
- 複数素材からの自動ラフカット(「メディア」パネルの「複数素材から自動ラフカット」。すべての動画素材を横断してハイライトを検出し、目標の尺に収まるよう自動選択。候補は個別にチェックのON/OFFで調整でき、素材の順番またはスコア順でタイムラインの末尾に一括追加できる)
- マイプリセット(「テキスト」タブの各テロップ、「BGM/SE」タブの各検索結果に★ボタンを追加。よく使うテロップの装飾スタイルや効果音をお気に入り登録しておくと、「プリセット」タブから再生位置への新規テロップ追加・SEトラックへの追加をワンクリックで行える)
- キーボードショートカットの常時ガイド表示+配置切替(タイムライン上部に主要アクションと対応キーを常時ラベル表示。Premiere Pro風・CapCut風のキー配置にワンクリックで一括切替可能)
- BPM解析とビート同期グリッド(音声トラックのBPMアイコンから、そのトラックの音声を解析してテンポを自動検出。タイムライン上にビートグリッド線を表示し、クリップのトリムやBGM/SEクリップの移動が自動でビートにスナップするため、カットや効果音をリズムに合わせて配置しやすくなる。グリッドはワンクリックで表示/非表示切替・削除が可能)
- キーワード連動オートSE(「プリセット」タブでキーワードと効果音(SEお気に入りから選択)の組み合わせを辞書登録しておくと、テロップ内にその単語が現れた瞬間を自動検出し、対応する効果音をタイムラインに一括配置できる。単語ごとの発話タイミングが分かっている場合はその時刻に、それ以外はテロップの開始位置に配置。配置後は各SEクリップを選択して音量調整・別の効果音への差し替え・開始位置の微調整が行える)
- クリップの複数選択+一括操作(タイムラインの動画クリップをShift+クリックで範囲選択、Ctrl(Cmd)+クリックで個別に追加/除外でき、選択中は速度の一括変更・まとめて削除・まとめてコピー&貼り付けが行える。貼り付けは選択中クリップの直後に元の並び順のまま挿入される)
- フレーム単位の再生位置移動(タイムライン・プレビューにフォーカスがある状態で←/→キーを押すと再生ヘッドが1フレームずつ、Shift+←/→で10フレームずつ移動。精密なカット位置合わせがしやすくなる)
- スナップのON/OFF切替(タイムラインのズームコントロール横の磁石アイコンでスナップ機能を一時的に無効化できる。設定は次回起動時も保持)
- クリップ複製ショートカット(Ctrl+D、または「複製」ボタンで選択中クリップ(複数選択時はまとめて)をその場で複製し、直後に挿入)
- タイムライン全体表示ズームボタン(現在のプロジェクトの長さ全体が横スクロールなしで収まるズーム倍率に自動調整)
- タイムライン上でテロップを直接ドラッグ操作(タイムラインのテロップレーンでブロックをクリックして選択、ドラッグして開始位置を移動、左右の端をドラッグして開始/終了時刻を個別にトリムできる。既存のスナップ機能にも対応)
- 全テロップの一括タイムシフト(「テキスト」パネルから、すべてのテロップの開始/終了時刻をまとめて±N秒ずらせる。クリップの挿入/削除でテロップがずれた際の再同期に便利)
- ハイライト検出に基づくサムネイル候補生成(「サムネ」パネルに「ハイライトから生成」ボタンを追加。均等間隔の抽出に加えて、AIが検出した音量変化やカット点などの見せ場からもフレーム候補を抽出できる)
- 投稿準備パネルのタイトル文字数表示(各タイトル案に文字数(◯/100)を表示し、YouTube検索結果で見切れやすい長さ(70文字目安)を超えると警告色で表示)
- AIおまかせ全自動編集(「メディア」パネルの「AIおまかせ全自動編集」。配置した動画素材のハイライトを検出し、傾向の異なる編集パターンを自動生成してカード一覧で提示。各カードにサムネイル・尺・カット数・トランジション種別を表示し、選択でタイムラインに追加、再生成で作り直せる。各案に👍👎でフィードバックすると好みの傾向をアプリ全体で記憶し、次回以降の生成でカット尺・トランジション・パターンの提示順に反映される(実際のML学習ではなく、傾向を記憶するルールベースのヒューリスティック)
  - 固定ヒューリスティックによる5パターン: ハイライト重視・ジャンプカット・ストーリー順・ロングテイク・ミックス
  - Gemini APIキーを設定している場合、シーン変化・音量ピークで検出したハイライト候補の代表フレーム画像を最大12件Geminiに見せて、表情の盛り上がり・感情の強さ・動きの激しさを0〜100点で採点させ、その結果をローカルのスコアとブレンドしてパターンの実際のセグメント選択に反映する(採点した候補数を画面に表示)
  - **AIディレクター(6つ目のパターン)**: 上記5パターンのような固定の組み立てロジックではなく、ハイライト候補一覧(素材名・区間・スコア・検出特徴)と好み傾向をGeminiにそのまま渡し、どのカットを使うか・どの順番で見せるか・カットごとのつなぎ方(カット/クロスフェード/フェード/ワイプ)・合計尺までを、視聴維持率を意識したプロ編集者的な判断としてGemini自身に一括で決めさせる。時系列順に並べ直したりしない、Gemini発の構成そのままがタイムラインに反映される。カードの説明文もGemini自身が書いた編集意図の説明がそのまま使われ、自動的に「AIのおすすめ」として提示される
  - **各パターンカードの「適用して自動で仕上げる」ボタン**: パターンをタイムラインに適用した上で、タイムライン全体をオフライン音声認識(Whisper)で自動的に文字起こしして字幕として追加し、Gemini APIキーを設定していれば生成された字幕内容を根拠に投稿メタデータ(タイトル案・概要欄・ハッシュタグ・固定コメント)まで一括で自動生成する。素材を置いてボタンを押すだけで、編集・字幕・投稿準備までをまとめて完了できる)
  - **ビートシンク(BGMトラックがある場合に追加されるパターン)**: 音声トラックに配置済みのBGMのテンポを既存のBPM解析機能でローカル解析し、ビート間隔(60/BPM)の整数倍にカット尺を揃えたパターンを追加提示する。クリップを時系列に並べるだけでカット点が自動的に拍に揃うため、Gemini APIキー不要でローカル完結。BGMトラックが存在しない場合はこのパターンは提示されない
  - **参考動画スタイル(参考動画を選んだ場合に追加されるパターン)**: 「参考動画を選ぶ」ボタンから「こんな感じで作りたい」という手本の動画ファイルを選択すると、その動画のカット間隔(平均ショット長)をシーン検出でローカル解析し、同じテンポでカット尺を揃えたパターンを追加提示する。Gemini APIキー不要でローカル完結。参考動画未選択時はこのパターンは提示されない
- 自動保存とクラッシュ復旧(編集中は1分ごとに未保存の変更を自動下書き保存し、クラッシュや強制終了の後に次回起動時「復元しますか?」と確認して下書きを復元できる。手動保存すると下書きは自動的に破棄される)
- 未保存の変更がある状態でアプリを閉じようとすると確認ダイアログを表示(誤操作による作業内容の消失を防止)
- 書き出し中のキャンセル機能(通常書き出し・バッチ書き出しの双方で、進行中のエンコードを「キャンセル」ボタンで中断可能。中断時は不完全な出力ファイルを自動的に削除)
- タブ切り替え・パネル折りたたみ中も処理が継続(ナレーション生成やゲームトレンド分析などAI/API処理の実行中に別のタブへ切り替えたりパネルを畳んだりしても、処理が中断されず結果が保持される)
- 素材ファイルの再リンク(プロジェクトを開いた際に参照先の動画・音声ファイルが移動/削除されて見つからない場合、メディアパネルに警告バッジと「再リンク」ボタンを表示。ファイルを選び直すとプロジェクト内の参照が更新される。見つからない素材が使われたままでは書き出しをブロックする)
- 音声トラック・PiP動画トラックのクリップも再生位置でカット(これまで動画トラックの本編クリップしか分割できず、BGM/ナレーションやPiPクリップは分割できなかった。各クリップのインスペクターの「カット」ボタン、またはショートカット(既定は`S`)で分割できる)
- 音声クリップのイン点・アウト点をトリム可能に(これまで音声クリップは配置後の長さ調整が一切できず、削除して入れ直すしかなかった。PiPクリップと同様にインスペクターから数値でイン点・アウト点を調整できる)
- 音声・PiPクリップもタイムライン上でドラッグしてトリム可能に(これまで動画トラックの本編クリップだけがクリップ端をドラッグしてトリムでき、音声・PiPクリップは数値入力でしか調整できなかった。クリップ左右の端をドラッグすることで、本編クリップと同じ感覚でトリムできる。スナップにも対応)
- 起動時のウィンドウサイズを記憶(初回起動時は画面いっぱいに最大化した状態で開き、以降は手動で変更したウィンドウのサイズ・位置・最大化状態を次回起動時に復元する。毎回固定サイズで開いていた不便を解消)
- タイムラインのショートカット一覧を折りたたみ可能に(常時表示されていたショートカットガイドを非表示にでき、その分プレビューやタイムラインの表示領域を広く使える)
- プレビューとタイムラインの境界をダブルクリックでプレビューを最大化/元に戻す(ドラッグでの微調整に加え、ダブルクリック一発でプレビュー領域を大きく確保でき、もう一度ダブルクリックすれば元のタイムライン高さに戻る)
- タイムライン上でクリップ間のトランジションを直接編集(これまでツールバーのドロップダウンからしか設定できなかったトランジション(カット/クロスフェード/フェード/ワイプ)を、タイムライン上のクリップ境界マーカーをクリックして開くポップオーバーから種別・長さを直接指定できる。設定済みのトランジションはマーカーが常時ハイライト表示されるため、ダヴィンチリゾルブのようにタイムライン上で編集点の状態を一目で把握できる)
- AIハイライト検出・全自動編集・ラフカットの精度を向上(これまで素材の長さに関わらずハイライト候補を1本あたり最大12個までしか検出しておらず、長尺素材ほど良い場面を取りこぼしやすかった。素材の長さに応じて候補数を最大40個まで動的に増やすよう変更。あわせてAIおまかせ全自動編集でGeminiに画像採点させる候補数(12→20)やAIディレクターに渡す候補プール(20→30)、ジャンプカット/ビートシンク/参考動画スタイル模倣パターンの候補プールも拡大し、より多くの候補から質の高い編集を組み立てられるようにした)
- Undo履歴の不具合を修正(自動テロップ生成や全自動仕上げで一度に大量の字幕を追加した際、字幕1つごとに履歴が積まれて「元に戻す」が1個ずつしか戻せず、履歴の上限(50件)を字幕だけで使い切って生成前の状態にまで戻せなくなることがあった。1回の生成をまとめて1つの履歴にするよう修正。また、選択中のクリップの範囲外で「分割」を実行した際、実際には何も分割されないのに無意味な履歴が1件積まれ、直後の「元に戻す」が効いたように見えない不具合も修正)
- 分離した音声の同期ズレを修正(クリップの「音声を分離」で作られた音声クリップは作成時の絶対位置に固定されており、その後に手前のクリップをトリム・削除・並び替えすると、映像だけが前後にずれて音声と口が合わない動画が何の警告もなく書き出されていた。分離音声は元のクリップに自動追従(位置・トリム同期)するよう修正し、元クリップを分割すると音声も一緒に分割される。音声クリップ側を手動で動かす/トリムすると追従は解除されて独立になり、インスペクターの「本編に追従中」バッジからも手動で解除できる)
- プレビューでBGM・ナレーション・効果音を再生(これまで音声トラックのクリップはプレビュー再生で一切鳴らず、書き出すまで音のバランスを確認できなかった。音声トラックのクリップがプレビュー再生・シークに追従して鳴るようになり、トラック/クリップ音量・ミュートも反映される。音声を分離したクリップは本編側の音声を自動ミュートし二重再生を防止。ダッキングは書き出し時のみ適用)

## 動作環境

- 対応OS: Windows / macOS / Linux(Electronアプリとして各OS向けにビルド可能)
- ffmpeg / ffprobe は `ffmpeg-static` / `ffprobe-static` としてアプリに同梱されているため、別途インストールする必要はありません
- 開発・ビルドには [Node.js](https://nodejs.org/)(LTS版推奨)と npm が必要です
- 一部機能(自動テロップの音声認識モデル)は初回実行時のみインターネット接続でモデルをダウンロードします。それ以外の基本編集機能はすべてオフラインで動作します

## 導入方法

npm install

## 使い方

### 基本的な編集の流れ

1. 左の「メディア」パネルの「動画」ボタンから動画ファイルを追加(複数選択可)。音声ファイル(BGM/ナレーション用)は隣の🎵アイコンから追加
2. 素材の「タイムラインに追加」ボタン、またはドラッグ&ドロップでクリップをタイムラインに配置
3. タイムライン上でクリップの端をドラッグしてトリム、ドラッグ&ドロップで並び替え、選択して分割(Sキー)・削除・速度変更・トランジション設定
4. 右パネルの「テロップ」でテロップを追加・編集(自動生成も可能)、「ボイス」でナレーションを合成、「BGM/SE」で音源を追加
5. 「サムネ」タブでサムネイル画像を生成、「投稿準備」タブでYouTube投稿用のタイトル・概要欄・ハッシュタグを自動生成
6. 「書き出し」タブでアスペクト比・解像度・画質を選んで書き出し

### AIによる自動編集を使う場合

素材を並べる作業自体をAIに任せたい場合は、以下の機能が使えます。

- **AIおまかせ全自動編集**: 「メディア」パネルの「AIおまかせ全自動編集」ボタンから、配置した動画素材のハイライトを検出させ、傾向の異なる5パターンの編集案を自動生成。気に入った案を選んでタイムラインに反映し、👍👎で評価すると次回以降の提案に好みが反映されます
- **複数素材から自動ラフカット**: 「複数素材から自動ラフカット」ボタンから、全素材のハイライトを検出し目標の尺に収まるよう自動選択(候補は個別に手動調整可能)
- **テンプレートからの自動カット**: 右パネルの「テンプレート」タブから、ショート動画の定番構成(フック→本編→CTA等)に沿って自動でタイムラインとテロップを生成
- **AIハイライト自動検出**: メディア一覧の各素材からシーンチェンジ・音量変化をもとにした見せ場候補を個別に確認

### 外部連携・APIキーの設定(任意機能)

以下はすべて任意機能です。使わない場合はキーを設定しなくてもアプリの基本機能(タイムライン編集・書き出し等)は問題なく使えます。キーはアプリ内の入力欄で設定するとブラウザのlocalStorageにのみ保存され、外部に送信されることはありません。

毎回入力欄に貼り直すのが面倒な場合は、プロジェクトルート(開発モード)またはアプリ実行ファイルと同じフォルダ(配布版)に `.env` ファイルを置いて起動時に読み込ませることもできます。書式は `.env.example` を参照してください。アプリ内の入力欄で値を入力するとその場でlocalStorageの値が優先され、`.env` の値を上書きします。

| 機能                                                       | 設定場所                                                            | 必要なもの                                                                                                           |
| ---------------------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| YouTubeトレンド調査                                         | 「YouTube」タブ                                                       | [Google Cloud Console](https://console.cloud.google.com/) で発行する YouTube Data API v3 のAPIキー(無料)             |

## 注意事項

- 字幕の焼き込みには `libass`(ffmpeg同梱)を使用しています。システムに日本語フォントが入っていない環境では字幕が正しく表示されない場合があります。
- YouTube関連機能は公式APIのみを使用し、動画・音声のダウンロードやスクレイピングは行いません。
- 自動テロップ(音声認識)は完全ローカルで動作しますが、初回実行時のみモデルファイル(数十〜百数十MB)をHugging Faceからダウンロードするためインターネット接続が必要です。ダウンロード後はオフラインで利用できます。
- ナレーション機能は実在の人物の声を模倣するものではなく、VOICEVOXが公式に提供するキャラクターボイスのみに対応しています。
- BGM・効果音ライブラリはJamendo/Freesoundの公式APIのみを使用しています。音源によってはクレジット表記などライセンス条件が付く場合があるため、検索結果の「ライセンス」リンクから利用条件を確認してください。
- ゲームトレンド分析でGeminiが提示するゲーム名・シーン提案は、その回に取得したYouTube急上昇動画のタイトルのみを根拠にしています。Geminiが学習した古い知識からの推測ではなく、常に最新の実データに基づく分析です。
