# VideoEditor

YouTubeショート動画向けの動画編集デスクトップアプリ(Electron + React + TypeScript)。

## 主な機能

- 動画・音声インポート、メタデータ取得、サムネイル生成
- クリップの右クリックメニュー(タイムラインのクリップを右クリックすると、分割・複製・コピー・貼り付け・トリム画面・音声の分離・削除をその場で選べる。音声・PiPクリップは分割と削除。ショートカットの表記も併記されるので、覚えながら使える)
- クリップをトラック間でドラッグして移動(音声クリップを別の音声トラックへ、PiPクリップを別の動画トラックへ、掴んで縦に動かすだけで移せる。移動先のトラックが光り、離した位置がそのまま新しい開始位置になる。1回の移動=Undo1件)
- ソースビューアで決めた範囲をタイムラインへドラッグ(イン/アウトを付けた「イン ○○ / アウト ○○」の表示をつまんで本編トラックへ落とすと、その範囲だけが落とした位置に挿入される。末尾へ追加ボタンと違って置く場所を選べる)
- お気に入りの効果音をタイムラインへドラッグ(「プリセット」タブのSEお気に入りを音声トラックへ直接落とせる。再生位置に置くボタンと違い、鳴らしたい時刻へそのまま置ける)
- メディアパネルからタイムラインへのドラッグ&ドロップ配置(素材を掴んでトラックへ落とすだけで配置できる。本編トラックはクリップの切れ目に挿入位置の線が出て、落とした場所に割り込む。音声トラック・動画トラック(PiP)は落とした時刻にそのまま置け、既存のスナップ(クリップの端・再生位置・ビート)にも吸着する。映像の無い素材は本編・PiPに、音の無い素材は音声トラックに落とせないよう、置けるトラックだけが光る)
- ファイルのドラッグ&ドロップ取り込み(エクスプローラ/Finderからアプリのウィンドウへ動画・音声ファイルを落とすとそのまま素材に追加。複数まとめて可。対応外の形式は無視して理由を表示)
- タイムライン編集(クリップ端をドラッグしてリアルタイムにトリム・カット・並び替え・削除・再生速度変更)
- 動画トラック+複数の音声トラック(BGM/ナレーション用、追加・削除・ミュート・音量調整)
- 音声分離: 音声付きの動画クリップを選択して「音声を分離」を押すと、そのクリップの音声だけを独立した音声トラックに切り出せる。動画側は無音になり、切り出した音声はBGM/ナレーションと同じように単独で音量調整・ミュート・移動ができる(再生速度が1x以外のクリップは分離不可)
- 複数動画トラック(PiP/顔出し合成): メインの動画トラックに加えて、「動画トラック(PiP)」を追加するとワイプ(ピクチャーインピクチャー)として画面に重ねて合成できる。トラックごとに表示位置(4隅から選択)・サイズ・表示/非表示を設定可能。プレビューでリアルタイムに合成表示され、書き出し時もffmpegのoverlayフィルタで同じ位置・タイミングに正しく合成される(重ねる動画自身の音声もミックスされる)。動画トラックを追加しない場合は今まで通り単一トラックとして扱われる
- クリップ間トランジション(クロスフェード/フェード/ワイプ)
- 無音区間の自動検出→確認→カット
- 自動テロップ生成(オフライン音声認識、日本語・英語・中国語・韓国語・スペイン語・フランス語・ドイツ語から音声の言語を選択可能。要インターネット接続は初回のモデルダウンロード時のみ)
- リッチなテロップ装飾(フォント・サイズ・縁取り・影・背景ボックス・文字間隔・複数行入力・回転・アニメーション)
- テロップのアニメーションはフェードイン・ポップイン・スライドイン(上/下)・バウンス・タイプライターの6種類から選択可能(書き出し時のASS字幕にも反映)
- テロップはプレビュー画面で直接ドラッグ、またはX/Y座標の数値入力で自由な位置に配置可能(書き出し時にも同じ位置・回転角度を反映)
- テロップのスタイルをワンクリックで複製可能
- 単語ごとのハイライト字幕(カラオケ字幕): 自動テロップ生成時に「単語ごとにハイライト」を有効にすると、発話に合わせて単語単位で色が切り替わる字幕を生成(ハイライト色は変更可能。書き出し時のASS字幕もカラオケタグ(\k)で同期再現)
- YouTube Shorts の実際の画面UI(いいね・コメント・共有・チャンネル情報)を重ねたプレビュー表示で、テロップが隠れないか確認可能
- プレビュー再生(9:16 / 16:9 アスペクト比切替対応)。実サイズ表示ボタンでプレビューを画面いっぱいに拡大表示(Escで解除)、音量調整・ミュート、再生バーをクリックしての任意位置シークにも対応
- ショート動画のトレンド構成テンプレート(フック→本編→CTA、ジャンプカット等の定番パターンを自動適用)
- YouTube Data API(公式)によるトレンド・キーワード調査(メタデータ表示のみ、動画のダウンロードは行いません)
- 書き出し画質(解像度480〜1440・圧縮率プリセット)を選択可能
- 長尺(2時間級)ソース動画にも対応した書き出し(ffmpegによるカット済みクリップのみを処理)
- VOICEVOX連携によるナレーション音声合成(ずんだもん等、公式キャラクターボイスのみ対応)
- 編集の効率化機能: Undo/Redo、キーボードショートカット、クリップのコピー&貼り付け、タイムラインのズーム、波形表示
- レイアウトのリサイズ(左右パネルの幅・プレビューとタイムラインの高さ境界をドラッグで調整可能。サイズは次回起動時も保持)。左右パネルの境界にある丸ボタンでメディアパネル・右パネルをそれぞれ個別に折りたたみ可能で、タイムラインの表示領域を最大化できる(折りたたみ状態も次回起動時に保持)
- タイムラインの再生位置(プレイヘッド)をドラッグでスクラブ操作可能(クリックでのジャンプに加えて、つまみをつかんで連続的に移動できる)
- 右パネルのタブをグループ分け(編集系/公開系)し、各タブにツールチップを追加
- プロジェクトの保存/読み込み(`.veproj`ファイル)、未保存変更のインジケーター
- 素材のアスペクト比がプロジェクトと異なる場合の警告表示(黒帯が入ることを事前に確認可能)
- スマートリフレーム(自動クロップ配置): アスペクト比が異なる素材について、黒帯(レターボックス)の代わりに映像の視覚的な情報量が多い領域を自動検出してクロップし、画面いっぱいに表示(トリム画面から実行、検出結果は手動で中央に戻すことも可能)
- 書き出し完了後にファイルを再生/フォルダを表示するボタン
- タイムラインのクリップをドラッグ&ドロップで並び替え
- AIハイライト自動検出(シーンチェンジ+音量変化を解析し、盛り上がり区間の候補を提示)
- サムネイル自動生成(タイムラインから候補フレームを抽出し、テキストを合成してダウンロード)
- テンプレートからの自動カット(素材のハイライト検出結果を使い、テンプレート構成に沿ってタイムラインとテロップを自動生成)
- BGM・効果音ライブラリ(Jamendo / Freesound の公式APIで著作権フリー音源を検索・プレビューし、音声トラックに直接追加)
- チャンネル分析(「チャンネル分析」タブ。チャンネルのURLを貼ると、公開されている投稿動画を実際に集計して分析。YouTube Studioの「Ask Studio」と違い、自分以外のチャンネルにも同じ計算をかけられ、チャンネルの外で起きていることまで調べる)
  - **平常運転を出してから測る**: 公開から14日以上経った動画の再生数の中央値を「平常運転」とし、各動画がその何倍だったかを表示。ショートと長尺は別々の基準で測るため、桁の違う2つを混ぜて長尺が一律「不振」になることがない
  - **外部ニュース・予定の取り込み**: Google検索(Geminiのグラウンディング)でチャンネルの題材に関する直近の出来事とこれからの予定を調べ、**出典リンクと検索に使った語を画面に表示**。企画案の「なぜ今か」がチャンネルの中の数字だけでなく、外の事実にも接地する
  - **競合との比較**: 比較したいチャンネルを1行に1つ入力すると、同じ計算をかけて並べて表示(登録者あたりの再生・平常運転・投稿頻度)。規模の違うチャンネルどうしを比べられる
  - **企画案**: 実測(どの動画がなぜ回ったか)と外部ニュースの両方を根拠にした企画を提示。根拠にした自分の動画はクリックでYouTubeを開ける
  - **効いている型**: タイトルの型(数字入り・【】・問いかけ・長さなど)と曜日別の平常比。標本が足りない型・曜日は数字を出さない(1本の当たりで法則を作らないため)
  - **追加の質問**: 実測と外部調査を根拠にしたチャット。「答える前にGoogle検索で調べる」を有効にすると、外の最新情報が必要な質問にも出典付きで答える
  - **取れない指標は取れないと言う**: クリック率・視聴維持率・インプレッション・視聴者層は公開APIでは取得できないため、画面に明示し、推測値を出さない(これらが必要な場合はYouTube Studioを併用してください)
- ゲームリサーチ(「今どのゲームを撮るべきか」を、YouTube公式APIの実データから調べる。実行するたびに最新データを取得)
  - **数える処理はAIを通さない**: AIの仕事は「タイトルからゲーム名を判定する」ことと「確定した順位に解説を書く」ことだけ。件数・チャンネル数・再生速度・新しさの集計と順位付けはアプリ側の計算で行うため、AIが数を数え違えても順位は狂わない
  - 再生速度による評価: 再生数の絶対値ではなく「再生数 ÷ 公開からの経過時間」で測るため、3日前に伸びた動画より6時間前に伸びている動画を上に置ける(公開直後の動画が跳ね上がらないよう分母には下限を設定)
  - YouTube検索による裏取り(既定でON): 上位候補について直近14日のショートを検索し直し、実際にショートが回っているかを確かめてから順位を付け直す。急上昇の長尺に名前が出ていても、ショートが1本も無いゲームは1位にしない
  - 採点の内訳を全部表示: 勢い(40点)・新しさ(25点)・広がり(20点)・ショート適性(15点)の内訳と、根拠になった動画のタイトル・チャンネル・再生数・経過時間をその場で開いて確認できる(各動画はクリックでYouTubeを開く)
  - 根拠の引用は番号で受け渡し: AIには根拠タイトルを書かせず番号だけを返させるため、画面に出る根拠は必ず取得した原文そのものになる
  - 1チャンネルの独走を除外: 同じチャンネルが何本出していても「広がり」の点は伸びない(そのゲームが流行っているのではなく、そのチャンネルが強いだけのため)
  - トレンド時系列比較: 前回の分析結果をローカルに保存し、「新規」「継続」のゲームを比較表示(表記ゆれを正規化して突き合わせるため、同じゲームが毎回「新規」にならない)
  - サムネイル視覚傾向分析: 上位動画のサムネイル画像をGemini(マルチモーダル)に渡し、配色・構図・文字入れの傾向を分析
  - バズる要素の構造化抽出: タイトルのフック手法(数字訴求・疑問形・煽り文句など)を分類して提示
  - 取得したデータについてのチャット質問(集計結果と急上昇リストだけを根拠に回答し、分からないことは「分からない」と答える)
- ラウドネス正規化(書き出し時に元動画・BGM・ナレーションの音量差をYouTube推奨値(-14 LUFS)へ自動で揃える、ON/OFF切替可能)
- バッチ書き出し(アスペクト比・解像度・画質の組み合わせを複数登録し、フォルダを選ぶだけで一括生成)
- BGMオートダッキング(音声トラックごとにON/OFF切替可能。本編の音声がある区間だけそのトラックの音量を自動で下げ、ナレーション/セリフを聞き取りやすくする)
- タイムラインのスナップ機能(クリップのトリムや音声クリップのドラッグ移動時に、再生位置・動画クリップの境界・他のクリップの端・テロップの開始/終了に自動で吸着)
- フィラーワード自動検出・カット(オフライン音声認識で「えーと」「あの」等の言い淀みを検出し、無音カットと同じUIで確認してから削除)
- テキストベース編集(クリップの発話内容を単語単位で文字起こし表示し、不要な単語・フレーズをクリック(Shift+クリックで範囲選択)して選ぶだけで、対応する動画区間を自動でタイムラインからカット。タイムラインで秒数を探す手間なく、テキストを読みながら編集できる)
- 投稿メタデータ自動生成(「投稿準備」タブ。タイムラインのテロップ内容とサムネイル候補フレームを根拠に、GeminiがYouTube投稿用のタイトル案(複数のフック手法別)・概要欄・ハッシュタグ・固定コメント案を作成。各項目をワンクリックでコピーしてそのままYouTube Studioに貼り付け可能。タイトル案・固定コメント案は個別に再生成も可能)
- 複数素材からの自動ラフカット(「メディア」パネルの「複数素材から自動ラフカット」。すべての動画素材を横断してハイライトを検出し、目標の尺に収まるよう自動選択。候補は個別にチェックのON/OFFで調整でき、素材の順番またはスコア順でタイムラインの末尾に一括追加できる)
- マイプリセット(「テキスト」タブの各テロップ、「BGM/SE」タブの各検索結果に★ボタンを追加。よく使うテロップの装飾スタイルや効果音をお気に入り登録しておくと、「プリセット」タブから再生位置への新規テロップ追加・SEトラックへの追加をワンクリックで行える)
- キーボードショートカットの常時ガイド表示+配置切替(タイムライン上部に主要アクションと対応キーを常時ラベル表示。Premiere Pro風・CapCut風のキー配置にワンクリックで一括切替可能)
- BPM解析とビート同期グリッド(音声トラックのBPMアイコンから、そのトラックの音声を解析してテンポを自動検出。タイムライン上にビートグリッド線を表示し、クリップのトリムやBGM/SEクリップの移動が自動でビートにスナップするため、カットや効果音をリズムに合わせて配置しやすくなる。グリッドはワンクリックで表示/非表示切替・削除が可能)
- キーワード連動オートSE(「プリセット」タブでキーワードと効果音(SEお気に入りから選択)の組み合わせを辞書登録しておくと、テロップ内にその単語が現れた瞬間を自動検出し、対応する効果音をタイムラインに一括配置できる。単語ごとの発話タイミングが分かっている場合はその時刻に、それ以外はテロップの開始位置に配置。配置後は各SEクリップを選択して音量調整・別の効果音への差し替え・開始位置の微調整が行える)
- クリップの複数選択+一括操作(タイムラインの動画クリップをShift+クリックで範囲選択、Ctrl(Cmd)+クリックで個別に追加/除外でき、選択中は速度の一括変更・まとめて削除・まとめてコピー&貼り付けが行える。貼り付けは選択中クリップの直後に元の並び順のまま挿入される)
- フレーム単位の再生位置移動(タイムライン・プレビューにフォーカスがある状態で←/→キーを押すと再生ヘッドが1フレームずつ、Shift+←/→で10フレームずつ移動。精密なカット位置合わせがしやすくなる)
- スナップのON/OFF切替(タイムラインのズームコントロール横の磁石アイコンでスナップ機能を一時的に無効化できる。設定は次回起動時も保持)
- クリップ複製ショートカット(Ctrl+D、または「複製」ボタンで選択中クリップ(複数選択時はまとめて)をその場で複製し、直後に挿入)
- タイムライン全体表示ズームボタン(現在のプロジェクトの長さ全体が横スクロールなしで収まるズーム倍率に自動調整)
- タイムライン上でテロップを直接ドラッグ操作(タイムラインのテロップレーンでブロックをクリックして選択、ドラッグして開始位置を移動、左右の端をドラッグして開始/終了時刻を個別にトリムできる。既存のスナップ機能にも対応)
- 全テロップの一括タイムシフト(「テキスト」パネルから、すべてのテロップの開始/終了時刻をまとめて±N秒ずらせる。クリップの挿入/削除でテロップがずれた際の再同期に便利)
- ハイライト検出に基づくサムネイル候補生成(「サムネ」パネルに「ハイライトから生成」ボタンを追加。均等間隔の抽出に加えて、AIが検出した音量変化やカット点などの見せ場からもフレーム候補を抽出できる)
- 投稿準備パネルのタイトル文字数表示(各タイトル案に文字数(◯/100)を表示し、YouTube検索結果で見切れやすい長さ(70文字目安)を超えると警告色で表示)
- AIおまかせ全自動編集(「メディア」パネルの「AIおまかせ全自動編集」。配置した動画素材のハイライトを検出し、傾向の異なる編集パターンを自動生成してカード一覧で提示。各カードにサムネイル・尺・カット数・トランジション種別を表示し、選択でタイムラインに追加、再生成で作り直せる。各案に👍👎でフィードバックすると好みの傾向をアプリ全体で記憶し、次回以降の生成でカット尺・トランジション・パターンの提示順に反映される(実際のML学習ではなく、傾向を記憶するルールベースのヒューリスティック)
  - 固定ヒューリスティックによる5パターン: ハイライト重視・ジャンプカット・ストーリー順・ロングテイク・ミックス
  - Gemini APIキーを設定している場合、シーン変化・音量ピークで検出したハイライト候補の代表フレーム画像を最大12件Geminiに見せて、表情の盛り上がり・感情の強さ・動きの激しさを0〜100点で採点させ、その結果をローカルのスコアとブレンドしてパターンの実際のセグメント選択に反映する(採点した候補数を画面に表示)
  - **AIディレクター(6つ目のパターン)**: 上記5パターンのような固定の組み立てロジックではなく、ハイライト候補一覧(素材名・区間・スコア・検出特徴)と好み傾向をGeminiにそのまま渡し、どのカットを使うか・どの順番で見せるか・カットごとのつなぎ方(カット/クロスフェード/フェード/ワイプ)・合計尺までを、視聴維持率を意識したプロ編集者的な判断としてGemini自身に一括で決めさせる。時系列順に並べ直したりしない、Gemini発の構成そのままがタイムラインに反映される。カードの説明文もGemini自身が書いた編集意図の説明がそのまま使われ、自動的に「AIのおすすめ」として提示される
  - **各パターンカードの「適用して自動で仕上げる」ボタン**: パターンをタイムラインに適用した上で、タイムライン全体をオフライン音声認識(Whisper)で自動的に文字起こしして字幕として追加し、Gemini APIキーを設定していれば生成された字幕内容を根拠に投稿メタデータ(タイトル案・概要欄・ハッシュタグ・固定コメント)まで一括で自動生成する。素材を置いてボタンを押すだけで、編集・字幕・投稿準備までをまとめて完了できる)
  - 生成中に画面を閉じても処理は中断されない。閉じている間もメディアパネルのボタンが「生成中...」と表示され、終わったら開き直すだけで結果が出る(字幕・メタデータまで一括で作る「適用して自動で仕上げる」も同様)
  - **ビートシンク(BGMトラックがある場合に追加されるパターン)**: 音声トラックに配置済みのBGMのテンポを既存のBPM解析機能でローカル解析し、ビート間隔(60/BPM)の整数倍にカット尺を揃えたパターンを追加提示する。クリップを時系列に並べるだけでカット点が自動的に拍に揃うため、Gemini APIキー不要でローカル完結。BGMトラックが存在しない場合はこのパターンは提示されない
  - **参考動画スタイル(参考動画を選んだ場合に追加されるパターン)**: 「参考動画を選ぶ」ボタンから「こんな感じで作りたい」という手本の動画ファイルを選択すると、その動画のカット間隔(平均ショット長)をシーン検出でローカル解析し、同じテンポでカット尺を揃えたパターンを追加提示する。Gemini APIキー不要でローカル完結。参考動画未選択時はこのパターンは提示されない
- 自動保存とクラッシュ復旧(編集中は1分ごとに未保存の変更を自動下書き保存し、クラッシュや強制終了の後に次回起動時「復元しますか?」と確認して下書きを復元できる。手動保存すると下書きは自動的に破棄される)
- 未保存の変更がある状態でアプリを閉じようとすると確認ダイアログを表示(誤操作による作業内容の消失を防止)
- 書き出し中のキャンセル機能(通常書き出し・バッチ書き出しの双方で、進行中のエンコードを「キャンセル」ボタンで中断可能。中断時は不完全な出力ファイルを自動的に削除)
- タブ切り替え・パネル折りたたみ中も処理が継続(ナレーション生成やゲームリサーチなどAI/API処理の実行中に別のタブへ切り替えたりパネルを畳んだりしても、処理が中断されず結果が保持される)
- 素材ファイルの再リンク(プロジェクトを開いた際に参照先の動画・音声ファイルが移動/削除されて見つからない場合、メディアパネルに警告バッジと「再リンク」ボタンを表示。ファイルを選び直すとプロジェクト内の参照が更新される。見つからない素材が使われたままでは書き出しをブロックする)
- 音声トラック・PiP動画トラックのクリップも再生位置でカット(これまで動画トラックの本編クリップしか分割できず、BGM/ナレーションやPiPクリップは分割できなかった。各クリップのインスペクターの「カット」ボタン、またはショートカット(既定は`S`)で分割できる)
- 音声クリップのイン点・アウト点をトリム可能に(これまで音声クリップは配置後の長さ調整が一切できず、削除して入れ直すしかなかった。PiPクリップと同様にインスペクターから数値でイン点・アウト点を調整できる)
- 音声・PiPクリップもタイムライン上でドラッグしてトリム可能に(これまで動画トラックの本編クリップだけがクリップ端をドラッグしてトリムでき、音声・PiPクリップは数値入力でしか調整できなかった。クリップ左右の端をドラッグすることで、本編クリップと同じ感覚でトリムできる。スナップにも対応)
- 起動時のウィンドウサイズを記憶(初回起動時は画面いっぱいに最大化した状態で開き、以降は手動で変更したウィンドウのサイズ・位置・最大化状態を次回起動時に復元する。毎回固定サイズで開いていた不便を解消)
- タイムラインのショートカット一覧を折りたたみ可能に(常時表示されていたショートカットガイドを非表示にでき、その分プレビューやタイムラインの表示領域を広く使える)
- プレビューとタイムラインの境界をダブルクリックでプレビューを最大化/元に戻す(ドラッグでの微調整に加え、ダブルクリック一発でプレビュー領域を大きく確保でき、もう一度ダブルクリックすれば元のタイムライン高さに戻る)
- タイムライン上でクリップ間のトランジションを直接編集(これまでツールバーのドロップダウンからしか設定できなかったトランジション(カット/クロスフェード/フェード/ワイプ)を、タイムライン上のクリップ境界マーカーをクリックして開くポップオーバーから種別・長さを直接指定できる。設定済みのトランジションはマーカーが常時ハイライト表示されるため、ダヴィンチリゾルブのようにタイムライン上で編集点の状態を一目で把握できる)
- AIハイライト検出・全自動編集・ラフカットの精度を向上(これまで素材の長さに関わらずハイライト候補を1本あたり最大12個までしか検出しておらず、長尺素材ほど良い場面を取りこぼしやすかった。素材の長さに応じて候補数を最大40個まで動的に増やすよう変更。あわせてAIおまかせ全自動編集でGeminiに画像採点させる候補数(12→20)やAIディレクターに渡す候補プール(20→30)、ジャンプカット/ビートシンク/参考動画スタイル模倣パターンの候補プールも拡大し、より多くの候補から質の高い編集を組み立てられるようにした)
- Undo履歴の不具合を修正(自動テロップ生成や全自動仕上げで一度に大量の字幕を追加した際、字幕1つごとに履歴が積まれて「元に戻す」が1個ずつしか戻せず、履歴の上限(50件)を字幕だけで使い切って生成前の状態にまで戻せなくなることがあった。1回の生成をまとめて1つの履歴にするよう修正。また、選択中のクリップの範囲外で「分割」を実行した際、実際には何も分割されないのに無意味な履歴が1件積まれ、直後の「元に戻す」が効いたように見えない不具合も修正)
- 分離した音声の同期ズレを修正(クリップの「音声を分離」で作られた音声クリップは作成時の絶対位置に固定されており、その後に手前のクリップをトリム・削除・並び替えすると、映像だけが前後にずれて音声と口が合わない動画が何の警告もなく書き出されていた。分離音声は元のクリップに自動追従(位置・トリム同期)するよう修正し、元クリップを分割すると音声も一緒に分割される。音声クリップ側を手動で動かす/トリムすると追従は解除されて独立になり、インスペクターの「本編に追従中」バッジからも手動で解除できる)
- プレビューでBGM・ナレーション・効果音を再生(これまで音声トラックのクリップはプレビュー再生で一切鳴らず、書き出すまで音のバランスを確認できなかった。音声トラックのクリップがプレビュー再生・シークに追従して鳴るようになり、トラック/クリップ音量・ミュートも反映される。音声を分離したクリップは本編側の音声を自動ミュートし二重再生を防止。ダッキングは書き出し時のみ適用)
- トランジション使用時の書き出しズレを修正(クロスフェード等はクリップ同士を重ねるため書き出し後の動画はタイムラインより短くなるが、テロップ・BGM・効果音・PiPはタイムライン上の絶対時間のまま焼き込まれていたため、トランジション以降のすべての要素がトランジションの合計秒数だけ後ろにズレて書き出されていた。書き出し時に各要素の時間をトランジションの重なり分だけ補正し、映像と一致する位置に配置するよう修正。進捗バーが100%に達しなかった問題も併せて解消)
- 保存後に「元に戻す」しても未保存扱いにならない問題を修正(保存直後にUndo/Redyoすると内容がファイルと食い違うのに未保存マークが付かず、保存ボタンが押せないまま・終了時の警告も出ない・自動保存も走らないため、Undoした内容が黙って失われる状態だった)
- テロップ入力・スライダー操作でUndo履歴が1文字ずつ積まれる問題を修正(テロップに文字を打つと1キーごと、音量やサイズのスライダーを動かすと1ピクセルごとに履歴が積まれ、30文字入力しただけで履歴上限(50件)を使い切っていた。さらに「元に戻す」が1文字ずつしか戻らず実用にならなかった。連続した同じ項目の編集は1つの履歴にまとめ、入力を止めると次の履歴に切り替わるようにした)
- クリップの分割・無音カット等でクロップ設定が失われる問題を修正(アスペクト比の違う素材に「クロップして画面いっぱいに表示」を設定していても、分割やカットを行うと設定が引き継がれず、書き出した動画に黒帯が戻っていた)
- トリム画面の「キャンセル」でクロップ設定が取り消せない問題を修正(トリム範囲は適用時に反映されるのに、クロップのチェックと自動検出だけは即座に反映されており、キャンセルしても元に戻らなかった。操作するたびにUndo履歴も積まれていた)
- 素材の一括インポートでUndo履歴が流し尽くされる問題を修正(1ファイルごとに履歴を積んでいたため、60本の素材をまとめて読み込むと履歴上限(50件)を使い切り、インポート前の作業に一切戻れなくなっていた。一括インポート全体を1つの履歴にまとめた)
- ナレーション生成・BGM追加のUndoが中途半端になる問題を修正(「素材追加→トラック作成→クリップ追加」が3つの履歴に分かれていたため、1回のUndoで空のトラックと未使用の素材だけが取り残されていた。1操作=1履歴にまとめた)
- ジャンプカット系テンプレートの適用でクロップ設定と音声分離状態が失われる問題を修正(クリップを細かく刻み直す際に設定が引き継がれず、黒帯が戻るだけでなく、音声を分離済みのクリップでは分離した音声と元の音声が二重に鳴る状態になっていた)
- キーワード連動SEの一括配置でUndo履歴が効果音の種類ぶん積まれる問題を修正(1回のスキャンで配置した内容がまとめて1回のUndoで戻るようにした)
- テロップの開始/終了時刻に不正な値を入力できる問題を修正(数値欄に負の値や「終了より後の開始時刻」を入力でき、その場合テロップがプレビューにも書き出しにも一切現れなくなっていた(理由の表示もなし)。負の時刻は字幕ファイルの時刻表記自体を壊すため、入力時に自動で補正するようにした。古いプロジェクトに不正な値が入っていた場合に備え、書き出し側でも同様に補正する)
- 効果音プリセットの追加でUndoが中途半端になる問題を修正(「素材追加→トラック作成→クリップ追加」が3つの履歴に分かれており、1回のUndoで空のSEトラックと未使用素材が残っていた。同じ効果音を何度も配置するとメディア一覧にも重複登録されていたため、既存の素材を再利用するようにした)
- トラックが増えると下のトラックに一切アクセスできなくなる問題を修正(音声トラックやPiPトラックを複数追加すると、タイムラインの表示領域に収まらないトラックがスクロールバーも出ないまま切り捨てられ、BGMやテロップのトラックが見えず操作もできなくなっていた。トラック領域全体を縦スクロールできるようにし、スクロールしてもトラック名とレーンの位置がずれないようにした)
- メディアパネルが横にはみ出す問題を修正(音声トラック名が長いと、追加先を選ぶドロップダウンがパネル幅を超えてメディア一覧に横スクロールバーが出ていた。行を折り返して収まるようにした)
- AIおまかせ全自動編集で同じパターンを二重に適用できてしまう問題を修正(「適用済み」と表示された後もボタンが押せてしまい、もう一度押すとパターンのクリップがまるごと追加されて動画の尺が倍になっていた。適用済みのパターンはボタンを無効化し、別のパターンを重ねて適用する場合は確認を表示するようにした)
- API通信のエラーメッセージが意味不明になる問題を修正(YouTube・Gemini・Jamendo・FreesoundのAPIがHTMLのエラーページや空の応答を返した場合、JSONの解析エラー(Unexpected token '<' など)がそのまま表示されていた。HTTPステータスを含む日本語のメッセージを出すよう統一)
- 投稿準備パネルで再生成に失敗すると既存の案が消える問題を修正(タイトル案・固定コメントの再生成でAIの応答が不正だった場合、表示中の案が空で上書きされていた。失敗時は元の案を保持してエラーを表示するようにした)
- 破壊的な操作に確認ダイアログを追加(音声トラック・PiPトラックの削除は中身のクリップごと消えるのに小さなゴミ箱アイコン1クリックで実行されていた。またテロップスタイル・効果音・キーワード辞書のプリセットはUndoの対象外(localStorage保存)で完全に消えてしまうため、どちらも実行前に確認するようにした)
- テンプレート適用・素材から自動カットで既存のテロップやタイムラインが無警告で置き換えられる問題を修正(自動生成した字幕やトリム済みタイムラインが1クリックで消えていたため、失われる内容を明示した確認ダイアログを追加)
- 無音カット・フィラーワードカット・テキストベース編集で分離音声が取り残される問題を修正(これらの機能はクリップを複数の断片に置き換えるが、分離済みの音声クリップは元の長さ・位置のまま残っていたため、映像だけが詰められて音声が最後まで全くズレた動画になっていた。カット後の各断片に合わせて分離音声も分割・追従するよう修正)
- クリップを削除しても分離音声だけが残り続ける問題を修正(削除したクリップの音声が、後ろから詰められてきた別の映像の上で鳴り続けていた。手動で位置や長さを編集して追従を解除済みの音声クリップはそのまま残す)
- ナレーション音声の消失を修正(VOICEVOXで生成したナレーションのWAVをOSのテンポラリ領域に保存していたため、PCを再起動するとファイルが削除され、保存済みプロジェクトのナレーションが「素材が見つかりません」状態になっていた。BGMライブラリと同じくアプリのユーザーデータ領域に保存するよう変更)
- BGM/効果音のダウンロード失敗時にファイルが残り続ける問題を修正(通信が途中で切れたり再生できない形式だった場合、不完全なファイルがユーザーデータ領域に残り、リトライのたびに蓄積してディスクを圧迫していた)
- 壊れたプロジェクトファイルを開いた際のエラー表示を改善(JSONとして壊れている・想定外の形式のファイルを開くと内部エラーがそのまま表示されていたため、原因の分かる日本語メッセージに変更)
- 複数クリップの速度一括変更で、音声を分離済みのクリップが黙って対象外になっていた問題を修正(対象外の件数を警告として表示)
- 安定性・信頼性のバグ修正まとめ: 通常書き出しとバッチ書き出しの同時実行を禁止(進捗バーの混線と、キャンセルできないゾンビエンコードが発生していた)/macOSでウィンドウを閉じて再度開くとIPCハンドラの二重登録でクラッシュする問題を修正/極端に短いクリップ(分割直後の断片など)にトランジションが設定されていると書き出し全体がffmpegエラーで失敗する問題を修正(自動的にカットつなぎへフォールバック)/Gemini応答が想定外の形式でも画面全体が真っ白にならないよう項目単位の検証を追加し、万一の描画エラー時も再読み込みで復帰できるエラー画面を追加/モーダルダイアログ表示中にDelete・分割・再生などのショートカットが背後のタイムラインに効いてしまう問題を修正/キーワード連動SEで同じ効果音ファイルが複数回マッチするとメディアパネルに重複登録される問題を修正/音声のない・壊れた素材のハイライト検出が「ハイライトなし」と誤報告される問題を修正(実際のエラーを表示)/複数ファイルの一括インポートで1つが壊れていると残りが取り込まれない問題を修正/自動テロップ・スマートリフレームの音声・フレーム抽出中にアプリ全体が固まる問題を修正(非同期化)/Ctrl+Sでの保存失敗が無言で握りつぶされていた問題を修正(ツールバーにエラー表示)

## 動作環境

- 対応OS: Windows / macOS / Linux(Electronアプリとして各OS向けにビルド可能)
- ffmpeg / ffprobe は `ffmpeg-static` / `ffprobe-static` としてアプリに同梱されているため、別途インストールする必要はありません
- 開発・ビルドには [Node.js](https://nodejs.org/)(LTS版推奨)と npm が必要です
- 一部機能(自動テロップの音声認識モデル)は初回実行時のみインターネット接続でモデルをダウンロードします。それ以外の基本編集機能はすべてオフラインで動作します

## 導入方法

### アプリとして使う場合

ビルド済みのインストーラーが欲しい場合は、下記「[セットアップ(開発者向け)](#セットアップ開発者向け)」の手順で `npm install` の後に `npm run build:win` / `build:mac` / `build:linux` のいずれかを実行してください。`dist/` フォルダにOS別のインストーラー(Windowsは `.exe`、macOSは `.dmg`、Linuxは `.AppImage` 等)が生成されるので、それを実行してインストールします。

### 開発モードですぐ試す場合

```bash
npm install
npm run dev
```

これだけでアプリが起動します。ffmpegは同梱済みなので追加インストールは不要です。

### セットアップ(開発者向け)

#### 事前準備

- [Node.js](https://nodejs.org/)(LTS版)と npm をインストール
- 本リポジトリをクローンまたはダウンロード

#### 依存パッケージのインストール

```bash
npm install
```

#### 開発モードで起動

ソースコードを変更しながらすぐに動作確認したい場合はこちら。ホットリロードに対応しています。

```bash
npm run dev
```

#### 型チェック・Lint

```bash
npm run typecheck
npm run lint
```

#### 配布用インストーラーのビルド

OSごとのインストーラー(Windows: `.exe`、macOS: `.dmg`、Linux: `.AppImage`等)を `dist/` フォルダに生成します。

```bash
# Windows向け
npm run build:win

# macOS向け
npm run build:mac

# Linux向け
npm run build:linux
```

ビルドが完了すると `dist/` フォルダにインストーラーが出力されるので、それを実行してインストールしてください。

## 使い方

### 基本的な編集の流れ

1. 左の「メディア」パネルの「動画」ボタンから動画ファイルを追加(複数選択可)。音声ファイル(BGM/ナレーション用)は隣の🎵アイコンから追加。**ファイルをアプリのウィンドウにドラッグ&ドロップしても追加できます**(動画・音声どちらでも、複数まとめて可)
2. 素材をタイムラインのトラックへドラッグ&ドロップして配置(「タイムラインに追加」ボタンでも可)。本編トラックは落とした位置に割り込み、音声・PiPトラックは落とした時刻に置かれます
3. タイムライン上でクリップの端をドラッグしてトリム、ドラッグ&ドロップで並び替え、選択して分割(Sキー)・削除・速度変更・トランジション設定。**クリップを右クリックすると分割・複製・削除などをその場で選べます**。音声・PiPのクリップは縦にドラッグして別のトラックへ移せます
4. 右パネルの「テロップ」でテロップを追加・編集(自動生成も可能)、「ボイス」でナレーションを合成、「BGM/SE」で音源を追加
5. 「サムネ」タブでサムネイル画像を生成、「投稿準備」タブでYouTube投稿用のタイトル・概要欄・ハッシュタグを自動生成
6. 「書き出し」タブでアスペクト比・解像度・画質を選んで書き出し

### AIによる自動編集を使う場合

素材を並べる作業自体をAIに任せたい場合は、以下の機能が使えます。

- **AIおまかせ全自動編集**: 「メディア」パネルの「AIおまかせ全自動編集」ボタンから、配置した動画素材のハイライトを検出させ、傾向の異なる5パターンの編集案を自動生成。気に入った案を選んでタイムラインに反映し、👍👎で評価すると次回以降の提案に好みが反映されます。**生成には時間がかかるため、待っている間は画面を閉じて別の作業を続けられます**(生成は裏で進み、終わったらボタンからいつでも結果を開けます)
- **複数素材から自動ラフカット**: 「複数素材から自動ラフカット」ボタンから、全素材のハイライトを検出し目標の尺に収まるよう自動選択(候補は個別に手動調整可能)
- **テンプレートからの自動カット**: 右パネルの「テンプレート」タブから、ショート動画の定番構成(フック→本編→CTA等)に沿って自動でタイムラインとテロップを生成
- **AIハイライト自動検出**: メディア一覧の各素材からシーンチェンジ・音量変化をもとにした見せ場候補を個別に確認

### 外部連携・APIキーの設定(任意機能)

以下はすべて任意機能です。使わない場合はキーを設定しなくてもアプリの基本機能(タイムライン編集・書き出し等)は問題なく使えます。キーはアプリ内の入力欄で設定するとブラウザのlocalStorageにのみ保存され、外部に送信されることはありません。

毎回入力欄に貼り直すのが面倒な場合は、`.env` ファイルを置いて起動時に読み込ませることもできます。置き場所は、プロジェクトルート(開発モード)、**アプリと同じフォルダ**(配布版: Windowsは実行ファイルの隣、Linuxは `.AppImage` の隣、macOSは `.app` の隣)、またはユーザーデータフォルダのいずれかです。書式は `.env.example` を参照してください。アプリ内の入力欄で値を入力するとその場でlocalStorageの値が優先され、`.env` の値を上書きします。

| 機能                                                       | 設定場所                                                            | 必要なもの                                                                                                           |
| ---------------------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| YouTubeトレンド調査                                         | 「YouTube」タブ                                                       | [Google Cloud Console](https://console.cloud.google.com/) で発行する YouTube Data API v3 のAPIキー(無料)             |
| チャンネル分析                                               | 「チャンネル分析」タブ                                                | 上記YouTube Data APIキー + Gemini APIキー(外部ニュース調査にはGeminiのGoogle検索グラウンディングを使用)                     |

### キーボードショートカット

タイムライン上部に主要ショートカットの常時ガイドを表示しており、隣のセレクトボックスから配置を「デフォルト」「Premiere Pro風」「CapCut風」に切り替えられます(切り替えは即座に反映され、次回起動時も保持されます。Premiere Pro風では分割がCtrl+K、CapCut風では分割がCtrl+Bに変わります。他のキーは共通)。以下はデフォルト配置。

| ---------------------------------- | ------------------------------- |
| Space                              | 再生/一時停止                   |
| S                                  | 選択中クリップを再生位置で分割  |
| Delete / Backspace                 | 選択中クリップを削除            |
| Ctrl(Cmd)+Z                        | 元に戻す                        |
| Ctrl(Cmd)+Shift+Z / Ctrl+Y         | やり直す                        |
| Ctrl(Cmd)+C / V                    | 選択中クリップのコピー/貼り付け |
| Ctrl(Cmd)+S                        | プロジェクトを保存              |
| Ctrl(Cmd)+ホイール(タイムライン上) | ズームイン/アウト               |

| Ctrl(Cmd)+クリップをクリック       | クリップを個別に選択/選択解除   |

## 注意事項

- 字幕の焼き込みには `libass`(ffmpeg同梱)を使用しています。システムに日本語フォントが入っていない環境では字幕が正しく表示されない場合があります。
- YouTube関連機能は公式APIのみを使用し、動画・音声のダウンロードやスクレイピングは行いません。
- 自動テロップ(音声認識)は完全ローカルで動作しますが、初回実行時のみモデルファイル(数十〜百数十MB)をHugging Faceからダウンロードするためインターネット接続が必要です。ダウンロード後はオフラインで利用できます。モデルはユーザーデータフォルダの `models/` に保存されるため、アプリを入れ直しても再ダウンロードは不要です(消したい場合はこのフォルダを削除してください)。
- ナレーション機能は実在の人物の声を模倣するものではなく、VOICEVOXが公式に提供するキャラクターボイスのみに対応しています。
- BGM・効果音ライブラリはJamendo/Freesoundの公式APIのみを使用しています。音源によってはクレジット表記などライセンス条件が付く場合があるため、検索結果の「ライセンス」リンクから利用条件を確認してください。
- ゲームリサーチが提示するゲーム名・シーン提案は、その回に取得したYouTube急上昇動画のタイトルと、裏取り検索で取得した動画のみを根拠にしています。Geminiが学習した古い知識からの推測ではなく、常に最新の実データに基づく分析です。順位とスコアはAIではなくアプリ側の計算(件数・チャンネル数・再生速度・公開からの経過時間)で決まります。
- チャンネル分析が使うのは、誰でも閲覧できる公開データ(チャンネル情報・投稿動画の再生数・尺・公開日時)だけです。クリック率・視聴維持率・インプレッション・視聴者層といったYouTube Studioの所有者向けデータは取得しません(取得にはOAuth認証とYouTube Analytics APIが必要です)。画面でもその旨を明示しています。
- チャンネル分析1回あたりのYouTube Data API消費は、チャンネル1件につきおよそ4ユニット(動画100本ぶん)です。ハンドルやチャンネルIDではなくチャンネル名で検索した場合のみ、追加で100ユニット消費します。
- チャンネル分析の「外部のニュース・トレンドも調べる」は、GeminiのGoogle検索グラウンディングを使用します。結果には必ず出典リンクと、実際に検索された語を表示します。
- ゲームリサーチの「裏取り」をONにすると、1回の分析でYouTube Data APIの検索を最大5回実行します(検索は1回100ユニット、既定の無料枠は1日10,000ユニット)。上限が気になる場合はチェックを外してください(裏取り以外の集計と順位付けはそのまま動きます)。
