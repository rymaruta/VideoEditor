# GPU の実機確認(GPU のある Windows PC で持ち主がする)

この開発環境には GPU が無いので、GPU で速くなる所(書き出しの NVENC・ローカル AI・文字起こし)は実機でしか確かめられない。
次の 3 つを、GPU のある Windows PC で確かめて結果を送る。

## 0. 準備

1. `npm ci` → `npm run build:win:test`(販売者が未定でも作れる確認用。インストーラは作らない)
2. `dist/win-unpacked/Tsunagi.exe` を起動する
3. NVIDIA の GPU なら、ドライバを新しくしておく(NVENC はドライバが古いと開けない)。タスク マネージャーの
   「パフォーマンス > GPU」で「Video Encode」と「Cuda」(または「3D」)のグラフを見られるようにしておく

## 1. 環境チェックを保存して送る

1. **ヘルプ > 環境チェック…** を開く(1〜2 分。試し書き出しをするので、その間は他の書き出しをしない)
2. 結果を確かめる:
   - **GPU**: 名前と VRAM(取れないときは「VRAM 不明」。下のローカル AI の欄にも VRAM が出る)
   - **ハードウェアのエンコーダ**: NVIDIA なら「NVIDIA NVENC(H.264)」が「使える」になっているか。
     Intel の内蔵 GPU なら Quick Sync、AMD なら AMF の行
   - **書き出しの速さ**: CPU(x264)と、使えるハードウェアの「再生の何倍」。「一番速いもの」の「CPU の何倍」
   - **ローカル AI**: 使う装置(cuda / vulkan / cpu)・VRAM・選ばれるモデル(VRAM 7GB 以上で 7B、16GB 以上で 14B、
     GPU なしは 1.5B)・判定
   - **文字起こし**: 試す順(DirectML(GPU) → CPU)と、onnxruntime の装置に `dml` があるか
3. 「テキストで保存…」で保存し、そのファイルを送る(API キーとパスの中の利用者名は伏せてある。送る前に中身を見る)

> 今の書き出しが GPU で使うのは **NVIDIA の NVENC だけ**。Intel の Quick Sync・AMD の AMF は環境チェックで
> 「使える」と出ても、書き出しは CPU(x264)で行う(使えると分かった PC が多ければ、対応を足すか決める)。

## 2. 3 時間の素材の書き出しを比べる

同じプロジェクトを、GPU(自動)と CPU(固定)で 1 回ずつ書き出して時間を比べる。

1. 3 時間前後の収録の素材でプロジェクトを作る(自動編集で仮編集まで作ったもの。テロップ・BGM が入っている方が実際に近い)。
   保存しておく
2. **GPU(自動)**: そのまま **ファイル > 書き出し…**(1080p・画質は既定)。書き出し中の表示が
   「書き出し中(N区間・4並列・GPU: NVENC)」になっていることを確かめ、かかった時間を記録する
3. **CPU(固定)**: アプリを閉じ、`Tsunagi.exe` と同じフォルダの `.env` に次の 1 行を足して起動し直す
   (`.env` が無ければ作る。終わったらこの行は消す)

   ```
   VE_VIDEO_ENCODER=libx264
   ```

   同じプロジェクトを同じ設定で書き出す。表示が「…・CPU: x264」になっていることを確かめ、時間を記録する
4. 送るもの: 2 つの時間、書き出した 2 つのファイルの大きさ、PC の構成(1. の環境チェック)、気づいたこと
   (途中で止まった・画面が固まった・GPU の使用率が上がらなかった など)。可能なら 2 つの動画を見比べて、
   画質に気になる違いが無いか

## 3. ローカル AI の構成の判定を確かめる

1. 1. の環境チェックの「ローカル AI」の欄を見る(ここではモデルをダウンロードしない)
2. 実際に使う: **自動編集の画面**の「構成」で「AI」を「このPC(無料・素材は外に出ない)」にし、「仮編集を作り直す」を押す。初回はモデルを
   ダウンロードする(7B は約 4.7GB、14B は約 9GB)
3. 確かめること:
   - 画面に出た装置・モデルが、環境チェックの「使う装置」「選ばれるモデル」と同じか
   - タスク マネージャーで、判定の間に GPU(Cuda)の使用率が上がるか
   - 構成の判定にかかった時間(素材の長さと一緒に)
   - 読み込みで止まった・落ちたときは、もう一度環境チェックをして「判定」の欄と、**ヘルプ > 不具合の報告用に情報をまとめる…**
     の保存したファイルを送る(読み込めなかったモデルは次から軽いモデルに下がる。その様子も環境チェックの判定に出る)
