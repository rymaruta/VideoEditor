# リリースノート用の文(下書き)

## 製品名が「Tsunagi」になりました

- 設定・自動保存・API キーはそのまま引き継ぎます。
- **アップデートの前に、前の版(VideoEditor)を終了してください。**
- Windows: タスクバー・スタートにピン留めした「VideoEditor」は切れます。「Tsunagi」をピン留めし直してください。古いショートカットは消してかまいません。
- Mac: 「アプリケーション」に `VideoEditor.app` が残ります(ゴミ箱へ入れてかまいません。設定は消えません)。保存した API キーを読むときに、キーチェーンの許可をもう一度聞かれます(「常に許可」を選んでください)。
- 詳しくは docs/PRODUCT_NAME.md。

## API キーの保存の変更

- API キー(Gemini・YouTube・Jamendo・Freesound)は、この版から OS の暗号化の仕組みで保存します。前の版で保存した鍵は初回の起動で自動で移します。**この版を使った後に前の版へ戻すと、前の版では API キーが空になります(入れ直してください)。** 別の PC へ設定を移したときも、鍵は入れ直しが要ります。
- 前の版が平文で保存していた鍵は、移した後に設定から消しますが、画面の保存領域(Chromium の localStorage。userData の `Local Storage/leveldb`)の古いファイルには、整理されるまでしばらく平文のまま残ることがあります。鍵が漏れたおそれがあるときは、各サービスで鍵を作り直してください。
- OS の暗号化が使えない PC(Linux で鍵の保管場所が無いときなど)では、鍵は今までどおり平文で保存します(欄にその旨を出します)。
