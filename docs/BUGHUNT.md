# バグ狩り（1時間おき / 潜在バグを探して即修正する）

このファイルは**バグ狩りロール専用**です。他のロールは書き込みません。
`BACKLOG.md` に書くと、実装・補充・検証の3ロールと毎回衝突するため分けてあります。

## このロールの立ち位置

| ロール | 見るもの | 動くとき |
|---|---|---|
| 検証 | **直近のコミットが壊していないか** | 壊れているときだけ直す |
| バグ狩り（これ） | **前からずっと壊れていたもの** | 毎回1件見つけて直す |

検証ロールは「壊れていなければ何も変更せず終了」なので、**最初から間違っていたコードは永久に拾えません**。
実際、60fps素材が常に30fpsで書き出されていた不具合は、尺が合っていてエラーも出ないため、
検証を何十回通しても素通りしていました。そこを掘るのがこのロールです。

## 1回の実行でやること

**1件だけ**見つけて、**その場で直して**、**push するまで**が1セット。
見つけて報告するだけで終わらせない。直せないものを見つけたら、次項の手順で候補に残す。

### 手順

1. **担当領域を1つ選ぶ。** 下の「領域の巡回表」で**最終掃引が一番古いもの**。
   同じ領域を続けて2回選ばない。
2. **`BACKLOG.md` の「再発防止チェックリスト」を全部読む。**
   これが探すための眼鏡です。各項目を「この領域でこれに違反している箇所はないか」という
   grep の観点に翻訳して、順に当てていく。項目数が多いので、当てた項目と結果を手元に控える。
3. **怪しい箇所を見つけたら、直す前に「本当に壊れているか」を実測で確かめる。**
   ここを飛ばすと、壊れていないものを「直して」しまう。実際に何度も起きています
   （呼び出し方を間違えて2件を誤検知、クリップ終端での分割を不具合と誤認、など）。
   実測とは、アプリを起動して同じ操作をする・ffprobe で数字を読む・DOM の値を読む、のいずれか。
4. **直す。** 進め方は `BACKLOG.md` の「実装の進め方」（設計 → 実装 → 単体 → 結合）に従う。
5. **同じ種類が他にないか grep で洗う。** 1箇所だけ直すと、残りが黙って壊れたままになる。
   （実例: 書き出しの `fps=30` を直したら、画面側にも `1 / 30` が3箇所あった）
6. **チェックリストに1行足す**（`BACKLOG.md` の「再発防止チェックリスト」）。
   既存項目と同じことを言い換えただけなら足さない。既存項目で拾えたなら、そう報告する。
7. このファイルの巡回表の日付と「見つけたもの」を更新して、コード変更と一緒にコミットする。

### 何も見つからなかったとき

**でっち上げない。** 「異常なし」で終えてよい。ただし巡回表は更新して、
**どのチェックリスト項目をどう当てて、なぜシロと判断したか**を1〜2行残すこと。
これが残っていないと、次回また同じ当て方をして同じ時間を溶かします。

### 直すのが大きすぎたとき

無理に大改造しない。`BACKLOG.md` の「候補」欄に
「◯◯の修正（バグ狩りで発見。症状は△△、原因の見当は□□）」として1件残し、
このファイルにも記録して終える。**症状と再現手順は必ず数字付きで書く。**

## 優先順位

同じ日に2つ怪しいものが見つかったら、**編集作業が止まる/出力が壊れるほう**を先に直す。

1. 出力が壊れる（尺ズレ・音ズレ・映像の欠落・書き出し失敗）
2. 編集内容が失われる（Undoで戻らない・保存で消える・参照が切れる）
3. 画面と出力が食い違う（プレビューで決めた見た目が出力で別物）
4. 操作が効かない・効きすぎる
5. 表示崩れ・文言

## 掃引の記録

新しいものを上に足す。1回1ブロック。

### 2026-08-12 書き出しパイプライン
`fps=30` / `settb=1/30` の決め打ちを発見。60fps素材が 30fps・330フレームで出力されていた
（尺は正しいのでエラーも警告も出ない）。素材から決める `targetFrameRate` を
`src/shared/frameRate.ts` に共通化して修正。画面側にも同じ決め打ちが3箇所あり、
60fps素材で「1フレーム移動」が2フレーム飛んでいたので同じ関数から求めるようにした。
実測: 60fps・660フレーム / framemd5 で複製でないことを確認 / 30fps素材は回帰なし。

### 2026-08-12 テロップ・字幕
`overlayPreviewStyle` で `fontSize` は換算済みなのに `outlineWidth` が固定倍率 `* 0.6`、
影が固定値 `2px 3px 4px` のままだった。縁取りは既定ONなので既定設定で必ずズレていた。
倍率を直した後の検算でまだ4倍ズレており、原因が `Math.max(1, Math.round(...))` の
丸めと下限だと分かって外した。全32通りで実測 1.0000 倍。
